## `/ whoami` — About Me

I'm **Yohannes Garomsa**, known in the cybersecurity community as **LOXLEGER**. I work across two complementary disciplines: **software development** and **cybersecurity**. I enjoy creating useful applications, understanding how systems work, and identifying ways to make them more resilient.

- **Development:** Building full-stack web applications and mobile experiences.
- **Offensive security:** Practicing ethical hacking, penetration-testing methodology, and vulnerability analysis in authorized environments.
- **Research:** Exploring bug bounty methodology, responsible disclosure, and web application security.
- **Engineering mindset:** Valuing clean architecture, practical problem-solving, documentation, and continuous improvement.

> **My principle:** Build with purpose. Test with permission. Secure by design.
